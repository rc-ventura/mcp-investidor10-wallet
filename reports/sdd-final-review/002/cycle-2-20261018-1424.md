## Tech Leader Verdict

### Architecture Assessment

**ADR alignment is strong.** The spec-002 surface (`bootstrap.py`, `server.main`, `wallet_client.validate_wallet`) is a faithful implementation of ADR-0010's five decisions:

- **Import purity** (ADR-0010 §1): `wallet_client.py:23` reads env but never validates at import; singletons use `_allow_unconfigured=True` (wallet_client.py:454-455); `server.py:33-43` `_LazyMemory` defers `resolve_memory_path()` to first attribute access. Clean-env import test confirms zero disk/network/env side effects.
- **Deterministic pipeline** (C3): `server.py:495-502` executes exactly `load_config → configure → resolve_memory_path → MemoryStore → validate_wallet → mcp.run`. Order matches the contract verbatim.
- **Canonical dir + symlink/TOCTOU hardening** (§2-3): `_ensure_canonical_dir` (bootstrap.py:98-108) uses `lexists`/`lstat` before `chmod`; `_atomic_copy` (116-144) opens `O_NOFOLLOW`, `fstat`s the actual descriptor, verifies written content, and the inode-recheck before `legacy.unlink()` (200-206) closes the substitution race; rollback on failure preserves the legacy file (208-219).
- **ADR-0002 boundary preserved**: `memory_store._load` (90-129) covers all degraded classes; `evaluate_alerts` (393-424) does the single all-or-nothing save after all mutations; `.broken-*` backups use microseconds + `O_EXCL` (131-142).
- **ADR-0009 language split**: all operator messages in `bootstrap.py` are PT-BR; all tool docstrings/`error.message` payloads are EN. Clean audience boundary.
- **ADR-0004 threat model**: residual TOCTOU windows and the unsanitized `WALLET_MEMORY_PATH` override sit *inside* the declared trust boundary — correctly classified INFO/LOW, not vulnerabilities.

**SOLID/robustness**: modules keep single responsibilities (bootstrap=config+filesystem, wallet_client=source access+validation, memory_store=persistence+domain state, server=tool surface). `SourceError`/`MemoryUnavailableError` give one structured failure path per ADR-0007. `_LazyMemory` is a justified trade-off (ADR-0010 Alternatives A) to preserve ~200 tests. Complexity is proportionate — ~1,670 LOC for 19 tools.

### Cross-Report Synthesis

**Pattern: the hardened core is hardened; the seams around it are not.** Both reports converge on the same two clusters, all inside `bootstrap.py`'s new code:

1. **Override branch bypass** (bootstrap.py:155-157) — `WALLET_MEMORY_PATH` returns verbatim: no strip, no parent-dir check, bypasses the 0700/symlink hardening. QA calls it LOW (same failure class as the cycle-1 fresh-install bug, confined to an explicit override), Security calls it INFO (inside ADR-0004's trust boundary). Same finding, two lenses — consistent.
2. **Path-identity + artifacts around the canonical file** — `abspath` string-compare (bootstrap.py:163) misses symlinked-path aliases (data preserved in `legacy-*` backup, but memory silently resets); `.gitignore` lacks `memory.json.legacy-*` so a conflict backup in a repo cwd is committable. Both are consequences of the *same* narrow edge: the cwd/canonical collision path.

These are **edge-hardening gaps in one new module, not systemic** — the mandated paths (NOVO_CANONICO, MIGRADO, CANONICO_WINS, same-path) each carry the full lstat/NOFOLLOW/rollback treatment. The remaining LOWs are where an operator-supplied value or an exotic fs alias routes around them. Nothing here blocks a v0.1.0 single-user publish: worst cases are silent degrade-to-`memory_unavailable` (a designed, reported state) or a preserved backup file — never corruption, never fabricated data, never a crash.
